# Ubuntu Nerd Font

The bundled `UbuntuNerdFontPropo-Regular.ttf` and `UbuntuNerdFontPropo-Bold.ttf` files come from the Ubuntu family in Nerd Fonts 3.5.1.

They are loaded directly by `template.tex` so PDF builds do not depend on fonts installed elsewhere on the system. See `LICENCE.txt` for the font license.
